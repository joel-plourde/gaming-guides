## Using the tracker

Field the required different unit types together and confirm the maximum synergy is active in the game:

- 6 types: Empire, Outlaw, Forest, Tribe.
- 4 types: Arcane, Abyss, Undead.
- 3 types: Celestial, Holy, Engineer.

Identical duplicates count once. Separate 2-star and 3-star units count as different types. Completing one wave with the full synergy active is a cautious practice; the exact achievement save timing is unverified.

Checkmarks save in your browser on your device. Use Export progress and Import progress to transfer them. A downloaded copy and the hosted page may use separate browser storage.

## Offline copies

Download either HTML file in this folder and open it in a browser. Unit images are embedded. No installation or server is required.

The short Pages URLs use the matching `ten-banners/index.html` and `wave-110/index.html` copies. Keep those copies in sync when updating the downloadable guides.
