# 🎮 Gaming Guides

A growing collection of practical gaming guides, visual references, and achievement trackers by Joel Plourde.

Built for quick reference while playing: illustrated units, clear upgrade paths, actionable strategy, and lightweight HTML pages you can download and open in a browser.

## Slotbound

The first two guides focus on surviving deeper Endless runs and completing the **Ten Banners** achievement.

| Guide | What you’ll find |
| --- | --- |
| [Wave 110 & Door Survival Guide](Slotbound/Slotbound_Wave_110_Door_Survival_Guide_V2.html) | Roster planning, replacements for General, alternative carries, level targets, awakenings, imprints and donor units, items, cores, positioning, and Host/door choices. |
| [Ten Banners Visual Tracker](Slotbound/Slotbound_Ten_Banners_Tracker.html) | All ten factions, their required synergy counts, illustrated starter → 2★ → 3★ promotion paths, rarity and promotion levels, and one completion checkbox per faction. |

### Wave 110 & Door Survival Guide

Plan the army before the next difficulty spike. This guide combines unit and investment recommendations with a preparation loop and situational Host choices, including what to change when the frontline collapses or damage falls behind.

Recommendations are starting points to adapt to your run, drops, and current game balance.

### Ten Banners Visual Tracker

Track maximum faction synergies across runs with a full, always-visible unit list.

- **6 different types:** Empire, Outlaw, Forest, Tribe.
- **4 different types:** Arcane, Abyss, Undead.
- **3 different types:** Celestial, Holy, Engineer.
- Check off each completed faction and see your overall progress.
- Export and import a JSON backup to move checkmarks between browsers or devices.

Identical duplicates count once. Separate 2★ and 3★ units count as different types when fielded together; promoting your only 2★ copy does not leave both types in the army.

The achievement requires activating each faction’s highest synergy tier. The exact save timing has not been verified; completing a wave with the full synergy active is a cautious practice, not a confirmed additional requirement.

## How to use

1. Download the repository using **Code → Download ZIP**, or clone it:
   ```bash
   git clone https://github.com/joel-plourde/gaming-guides.git
   ```
2. Open either HTML file inside the `Slotbound` folder in your browser.
3. Keep the guide open beside the game.

**No installation, build step, account, or local server required.** Both guides include their unit images directly in the HTML and can be read offline. External reference links require internet access.

The GitHub repository shows HTML source. Use the live links above to read in your browser, or download the standalone HTML files for offline use.

## Tracker saves

Banner checkmarks are stored in your browser on your device—not in this repository or your Steam save. Moving or renaming the file, changing browsers, or clearing browser data can affect access to saved progress.

Use **Export progress** before making those changes, and **Import progress** to restore your backup. Checkmarks do not synchronize automatically between devices.
